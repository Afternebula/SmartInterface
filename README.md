# Presentation Clicker

#Модуль для бесконтактного управления презентации с помощью маркера синего цвета

## Особенности
* Быстрый старт:

* Перейдите в releases и скачайте архив.
* Распакуйте в желаемое место на диске.
* Запускайте PresentClick.exe.
* Откройте и кликните на выбранную презентацию.
* Листайте слайды с помощью синего предмета, проводя влево/вправо перед камерой.

# SmartInterface (В разработке)
Модуль бесконтактного управления интерфейсом с помощью компьютерного зрения (C++ / OpenCV).

### Текущий функционал:
* Трекинг объектов (управление презентацией с помощью синего маркера через веб-камеру).

### Ближайшие обновления:
* Миграция на полноценное распознавание и обработку кастомных жестов рук без использования маркеров.
* Оптимизация задержек (latency) для работы в реальном времени.
* Юнит-тесты для базовых алгоритмов филтьрации видеопотока (Google Test / Catch2).
* Замена метода измерения времени sleep на chrono.
* Текущий модуль реализован под Windows. В планах - абстрогировать работу с ОС через условную компиляцию (#ifdef _WIN32), поддержка uinput для Linux.
