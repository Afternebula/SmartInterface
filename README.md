# Presentation Clicker

#Бесконтактное управление презентации с помощью маркера синего цвета

## Особенности
* Быстрый старт:

- Перейдите в releases и скачайте архив
- Распакуйте в желаемое место на диске
- Запускайте PresentClick.exe
- Откройте и кликните на выбранную презентацию
- Листайте слайды с помощью синего предмета, проводя влево/вправо перед камерой.

*Реализация поиска камеры не доработана, из-за чего устройство может не определяться.
Если веб-камера не определяется, попробуйте переподключить её в другой порт.
